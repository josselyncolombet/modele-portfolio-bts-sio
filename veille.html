L'authentification sans mot de passe

Les passkeys, FIDO2 et WebAuthn remplacent peu à peu les mots de passe, première cause des comptes piratés. J'ai choisi ce sujet parce qu'il touche directement les applications que je développe : je le suis chaque semaine depuis septembre 2024.

Synthèse d'avril 2026

Où en est le sujet

Les passkeys fonctionnent dans les principaux navigateurs et systèmes, et arrivent dans les outils des entreprises. Pour une organisation, la question n'est plus technique : c'est la procédure, quand un agent s'inscrit, perd son appareil ou quitte la structure.

Pour un développeur, WebAuthn s'ajoute à côté du mot de passe sans le supprimer d'un coup. C'est ce que j'ai proposé pour l'application de prêt de matériel pendant mon stage de 2e année.

Mes dernières notes

  1. 14/04/2026

    Les passkeys arrivent dans les entreprises

    Les gestionnaires de mots de passe professionnels savent maintenant stocker des passkeys et les partager entre collègues.

    Ce que j'en retiens : quand un agent quitte la collectivité, il faut révoquer ses clés comme on désactive son compte : à prévoir dans la procédure de départ.

    Source : FIDO Alliance

  2. 24/03/2026

    Une passkey, combien de facteurs ?

    J'ai relu les recommandations de l'ANSSI sur l'authentification multifacteur. Une passkey combine un facteur de possession, l'appareil, et un facteur local : l'empreinte ou le code de l'appareil.

    Ce que j'en retiens : c'est une authentification à deux facteurs sans rien à taper : un bon argument pour convaincre un utilisateur.

    Source : ANSSI

  3. 03/03/2026

    WebAuthn ne fonctionne qu'en HTTPS

    Sur ma page de démonstration, dans une machine virtuelle, la création de clé échouait. Le navigateur exige un contexte sécurisé : HTTPS, ou localhost.

    Ce que j'en retiens : pour l'application de prêt, le serveur de test devra avoir un certificat.

    Source : MDN Web Docs

  4. 10/02/2026

    Ma proposition au service informatique

    J'ai présenté en dix minutes à mon tuteur la connexion par clé d'accès pour l'application de prêt : moins de mots de passe oubliés, et aucun mot de passe à voler.

    Ce que j'en retiens : il l'a inscrite dans la feuille de route du service pour la rentrée.

    Source : Ma réalisation : l'application de prêt

  5. 20/01/2026

    Et si l'on perd son téléphone ?

    Il existe deux familles de passkeys : celles qui se synchronisent entre les appareils d'un même compte, et celles liées à un seul appareil, comme une clé physique.

    Ce que j'en retiens : dans une organisation, chaque agent a besoin d'un moyen de secours : une seconde clé, ou une procédure au service informatique.

    Source : FIDO Alliance

  6. 09/12/2025

    La CNIL et les mots de passe

    La recommandation de la CNIL sur les mots de passe raisonne en force du mot de passe plutôt qu'en règles de composition imposées.

    Ce que j'en retiens : tant que les mots de passe restent, la prochaine version de l'application de réservation devra suivre cette recommandation.

    Source : CNIL

  7. 18/11/2025

    FIDO2, c'est WebAuthn plus CTAP

    WebAuthn relie le site au navigateur et est normalisé par le W3C ; CTAP relie le navigateur à l'authentificateur, clé USB ou téléphone.

    Ce que j'en retiens : en développement, je n'écris que la partie WebAuthn : le navigateur et le système gèrent le reste.

    Source : W3C, spécification WebAuthn

  8. 21/10/2025

    Pourquoi une passkey résiste à l'hameçonnage

    Une passkey est liée au nom de domaine du site qui l'a créée : sur un faux site, le navigateur ne la propose même pas.

    Ce que j'en retiens : c'est la vraie différence avec un code reçu par SMS, qu'on peut recopier sur un faux site.

    Source : MDN Web Docs
